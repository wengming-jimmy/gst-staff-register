# GST 工作人員登記站

粉紅魔法風格的 GST 工作人員登記程式，比照「工作人員魔法登記站」做法。

- 前台 `index.html`：先選男生／女生，再填姓名、電話、Email、生日（年份可不填）、衣服尺寸、飲食習慣（葷／素）、組別（GST 協調長、GST 副協調長、工作組 16 組＋其他，共 19 個；選「其他」時多一格自填所屬單位）。填完依星座優點送上專屬鼓勵，資料寫入 Google 試算表。
- 活動：GST 全球八大志業公益嘉年華，115年12月19日（星期六），台北市花博公園。
- 後台 `admin.html`：公開頁無連結，首次開啟需自設密碼（本機簡易鎖）。可重新載入、更改資料（含組別）、刪除、匯出 CSV。
- 試算表：GST工作人員登記，分頁「登記表」，11 欄：填寫時間、性別、姓名、電話、Email、生日、星座、衣服尺寸、飲食習慣、組別、自填單位。
- 後端：Apps Script `Code.gs`，部署為網路應用程式後，把正式 /exec 網址填入 `config.js` 的 APP_API。

安心提醒：只收登記所需資料，不收密碼、身分證、銀行帳號或驗證碼。
